# 손끝에서 열리는 크리스마스 · 스노우볼 세계여행

뉴욕을 시작으로 제작하는 1인 인터랙티브 미디어아트입니다. MediaPipe 손·얼굴 추적과 Blender/Three.js 3D 도시, 실시간 눈, 속도가 변하는 캐롤을 연결합니다.

## 실행

macOS에서 `3D 스노우볼 실행.command`를 실행하고 Chrome으로 http://127.0.0.1:8877/ 에 접속합니다. Python 3가 필요합니다.

- C자 모양으로 잡고 충분히 왕복 흔들면 같은 도시 안으로 진입합니다.
- 손을 펴면 놓습니다. 도시에서는 고개로 상하좌우를 둘러보고 주먹을 약 1초 유지하면 돌아옵니다.
- 카메라 없이 마우스·터치 시험도 가능합니다.

## 폴더

- `웹체험_3D`: 현재 실시간 3D 체험과 모델·추적 라이브러리
- `웹체험`: 이전 이미지 방식 원본
- `Blender`: 편집용 모델, 버전별 결과, 재질 적용·내보내기 스크립트
- `AI재질`, `무료소스`: 재질 이미지와 외부 소스/출처
- `미리보기`, `제작기록`: 확인 화면, 제작·검증 기록

현재 핵심 체험 프로토타입입니다. 실제 웹캠 감도·스피커 청감·75인치 설치·장시간 무인 운영은 현장 검증이 필요합니다. 자세한 내용은 `3D 버전 사용안내.txt`, `제작기록/3D-검증결과.txt`를 참고하세요.

외부 소스의 권리는 각 제공자의 라이선스를 따릅니다. 저장소 전체에 별도 공개 라이선스를 부여하지 않습니다.
