2026-11-11 · v06 매장 모델링 및 재질 보완

사용자 요청: 책상·배경 모델링, 스노우볼 접지, 실사에 가까운 표면 재질, 도시 안의 강설.

변경
- 배경 사진 합성 대신 shop.glb 사용: 실제 두께의 카운터·캐비닛, 아치·기둥·창틀, 책장·개별 책·표지·종이·금박 제목, 선물·황동 화병·리스·가랜드·창밖 가지.
- 카운터 상면 y=0. BASE 메시 경계로 바닥 높이를 측정해 모델 배치. 기울 때는 보수적인 경계상자 기준으로 책상 관통 방지.
- 색상만 남던 웹 변환을 수정. glTF에 normal/roughness/occlusion 맵을 연결. CC0 벽돌·목재·눈과 기존 AI 석재·에나멜·황동·수피·잎 이미지 사용.
- 돌·목재 색과 광량 조정, 건물/책장/소품 그림자, 실제 매장을 캡처한 유리 반사. 타워 돌출 띠·문틀·문손잡이 추가.
- 도시 눈 1800개: 가까운 650개와 먼 눈을 분리 배치, 거리별 크기·속도·가림 적용, 바닥 도달 시 위에서 다시 낙하.
- 도시 외곽 눈 지면·거리에도 반복 PBR 재질 적용.

반복 검수
1차: 모델과 재질 로드·접점0 확인. 유리 반사 과다/아치 이음/단순 가지 발견.
2차: 연속 아치, 실제 매장 반사, 요철 대비, 건물 표면 디테일. 도시 강설 확인.
3차: 잎·책의 입체 형상과 표지 질감, 들고 유지→내려놓기 확인.
4차: 솔잎 배열·초록 책상 재질·책장 그림자·지속 지연만 화질 조절하도록 정리.

실제 확인
- Chrome 1920x1080 합성 입력: 모델 로드·흔들기·도시 진입·시야 끝·복귀.
- rest contactGap=0, held contactGap=.22, release 후0. 실제 센티미터 단위가 아닌 장면 좌표.
- 최종 3D 눈·잡기 회귀 검사 통과: verification/check-3d.mjs.
- 도시 상태 citySnowVisible=true, citySnowCount=1800. 프레임별 입자 높이 변경과 화면 낙하 확인.
- 현재 컴퓨터의 1920x1080 상태 표본 약60fps. 현장 하드웨어·웹캠 동시 추론·장시간 보장 아님.
- 실제 내보낸 재질 수/맵 수: v06-pbr-export-audit.json.

한계
