# Mobile — 기존 3D 디자인 경량판

사용자 정정(2026-11-13): 이미지 기반 2D 버전은 사용하지 않는다. 기존 Blender 스노우볼과 도시 형태를 유지하고 텍스처와 눈 계산을 줄인다.

- 브랜치: codex/mobile. 기존 경량판 미커밋 변경은 원래 체크아웃에 보존.
- 실행: 저장소 루트에서 HTTP 서버 실행 후 /mobile/ 열기. 기존 웹체험_3D의 UI/입력/음악/손 모델 모듈을 공유하므로 mobile 폴더만 분리 배포하면 안 된다.
- 파생 모델: 원본 56,430,576B → 20,982,432B. 이미지 15개, 이미지 버퍼와 UV를 제거. 원본 위치/법선/인덱스/노드 변환 동일성을 check-model.py로 검증.
- 표면: 텍스처 대신 단색과 Lambert 조명. 원래 색 계열을 대체값으로 지정했으며 사진 질감과 반사는 생략.
- 스노우볼 눈: 400개의 단순 입자. 기존 유체/지붕 충돌 계산, 6,000개 장식 눈 제거. 눈은 바닥에 가라앉으며 지붕별 정밀 적층은 하지 않는다.
- 도시 눈: 1,800 → 250, 단순 원형 입자. 먼 반복 도시 11 → 4개, 하늘/원경 이미지 로딩과 실시간 원경 텍스처 생성 제거.
- 환경 반사 생성과 안티앨리어싱 제거, 렌더 해상도 비율 최대 .85. 기존 손 위 눈 표현은 유지.
- 방/눈보라 이미지 대신 CSS 단색·그라데이션. 원본 디자인의 3D 모델은 교체하지 않음.

검증: 모델 구조/바이너리 동일성 검사 통과, 400개 입자 1,800프레임 유한 좌표 검사 통과, JS 문법 검사 통과. 앱 내 브라우저 390×844에서 모델 로딩 및 도시 전환 확인. 도시 진입 중 관측 60fps/렌더 1.2ms는 작업 컴퓨터 측정이며 실제 저사양 모바일 보장 수치가 아니다. 실제 휴대폰/카메라 검증 및 공개 배포는 미완료.

잘못 만든 이미지 기반 초안은 /tmp/snowglobe-mobile-image-draft에만 보관, 현재 mobile 구현에서 사용하지 않음.

가로형: 높이 600px 이하 가로 화면에서 동작 안내를 왼쪽, 웹캠을 오른쪽, 버튼을 하단에 배치한다. 인트로/행운 문구를 낮은 화면에 맞춰 축소하고 화면 회전 시 기존 3D 카메라 resize를 사용한다.

컴퓨터 웹캠: 첫 화면의 ‘웹캠으로 시작’과 체험 하단의 ‘웹캠 켜기’를 같은 카메라 연결 흐름에 연결했다. 연결 후 ‘웹캠 끄기’는 스트림을 종료하고 마우스 체험의 처음으로 전환한다. 브라우저 권한 대기/차단/카메라 미연결 안내와 재시도는 기존 흐름을 유지한다.

휴대폰·데스크톱 공용: 같은 /mobile/ 주소에서 카메라로 시작한다. 전면 카메라는 ideal 선호값으로 요청하여 컴퓨터 기본 웹캠도 사용할 수 있다. 영상은 muted/playsinline으로 표시한다. 휴대폰 접속에는 HTTPS 배포 주소가 필요하며 컴퓨터의 127.0.0.1 주소를 휴대폰에서 열 수는 없다. 실제 iOS/Android 기기 검증은 별도로 필요하다.

배경 복원: 상점 배경 1280px JPEG(195,367B), 하늘 1024px JPEG(47,582B), 투명 뉴욕 원경 1024px PNG(300,903B). 합계 543,852B. 기존 하늘 구체/원경 원통에만 텍스처를 적용하고 모델의 단색 재질, 눈 개수, 환경 반사 비활성화는 유지한다. 앞의 배경 제거 설명은 이 변경으로 대체한다. JS 문법 및 로컬 HTTP 이미지 응답 확인, 실제 휴대폰 성능 검증은 미완료.

스노우볼 배경: 사용자 요청으로 상점/책상 사진을 다시 제거하고 초록 그라데이션으로 복원했다. 도시 하늘과 먼 뉴욕 원경은 유지한다. shop.jpg는 사용하지 않는다.
