# 뉴욕 스노우볼 핵심 체험 시험

사용자의 새 전시 프로젝트다. 상위 폴더의 꽃 프로젝트는 수정하지 않는다.
프로젝트의 karpathy-guidelines를 적용하고 사용자가 요청한 현재 단계만 진행한다.

## 사용자 확정 조건
- 전시 《손끝에서 열리는 크리스마스》, 콘텐츠 《스노우볼 세계여행》.
- 14일, 매일 09:00~18:00, 20~30대, 75인치 스크린 한 대·웹캠·스피커·노트북.
- 한 번에 1명, 최대 90초, 도시 한 곳만 방문해도 됨. 조기 종료 가능.
- 뉴욕·파리·서울. 음악은 같은 곡의 음높이를 유지하고 흔들림에 따라 빨라짐.
- 전체 전시 16,000명과 개별 체험 이론상 최대 5,040명(14일 × 9시간 × 시간당 40명, 교대 시간 제외)을 구분한다.
- 현재 단계: 이틀 개발용 뉴욕 스노우볼 핵심 시험. 전체 전시 운영 완성으로 설명하지 않는다.

## 최신 그래픽 요청 / 2026-11-11
- 사용자 제작 요정 영상의 캐릭터·재질·조명·크기 관계·공간감을 모든 그래픽에 이어간다.
- 브랜드 없는 매장 카운터의 스노우볼에 요정이 날아와 흔든다. 크리스마스 소품과 눈을 추가한다.
- 공유 참고 https://higgsfield.ai/s/G_JaEgpcJbQ 와 사용자가 보낸 두 Downloads 영상을 확인했다. 원본은 수정하지 않았다.
- 안내 UI는 짙은 초록, 금색 이중 테두리, 크림색 픽셀 글꼴, 동작에 따라 채워지는 3개 아이콘과 짧은 피드백이다.
- 영문 Press Start 2P와 한글 Neo둥근모를 로컬에 보관한다. 참고 브랜드·게임 내용은 작품 화면에 사용하지 않는다.

## 현재 구현
- 별도 로컬 웹 앱: index.html, serve.py, 스노우볼 실행.command. http://127.0.0.1:8876/.
- app.js는 art-scene.js를 사용한다. 기존 scene.js의 Three.js 단순 도형 장면은 현재 사용하지 않는다.
- Higgsfield에서 생성한 매장 배경, 투명 스노우볼, 뉴욕 도시 이미지와 5초 요정 영상을 조합한다.
- 이미지 층의 확대·이동·전환과 실시간 눈을 결합한 2.5D 방식이다. 실제 3D 건축 내부로 카메라가 진입하는 구현이 아니다.
- fairy-video.js에서 요정 영상의 파란 배경을 제거해 합성한다. 날개·팔 동작은 생성 영상이고 전체 위치·회전·속도는 입력에 반응한다. 손 접점은 근사 배치이며 관절 추적이 아니다.
- 영상 실패 시 assets/fairy.png를 대체 이미지로 사용한다. 예전 assets/christmas-shop.png는 현재 미사용이다.
- MediaPipe 한 손 추적과 마우스·터치 시험. 최초 입력 후 약 1.6초 동안 요정이 접근한다.
- 유리구 안 눈 1,000개, 도시 눈 230개. 흔들기 강도에 반응하고 멈추면 가라앉는다.
- 같은 합성 징글벨 후렴을 고정 음높이 72~158 BPM으로 연주한다.
- 빠른 방향 전환 4회와 충분한 에너지에서 3.6초 눈보라 전환. 도시에서 마우스 좌우 이동으로 풍경을 조금 둘러볼 수 있다.
- 진행 0/3→3/3, 초기화, 음소거, 카메라 오류 안내. 모델·폰트·영상은 로컬 파일이며 카메라 영상 저장·전송 없음.
- 문·제자리걸음·도시 선택·고개 추적·90초 회차·무인 초기화는 아직 구현하지 않았다.

## 제작 기록
- assets/higgsfield-production.json: 원본 참고 프롬프트, 수정 프롬프트, 모델·작업 ID·파일·견적.
- 새 작업 4개 완료: 요정 영상 1개와 이미지 3개. 견적 합계 43.25 크레딧. 최종 실제 차감량은 도구에서 제공하지 않았다.
- 생성 결과는 참고 영상의 정확한 복원이나 동일 픽셀 결과가 아니다. 사용자가 시각적 연속성을 직접 확인하는 단계다.

## 이번 버전 확인
- 실제 Chrome 마우스 입력: 요정 접근과 영상 재생, 눈 반응과 BPM 변화, 아이콘 0/3→3/3, 뉴욕 도착, 좌우 보기, 매장 복귀 확인.
- 화면 기록: verification/arcade-ui/01-fairy-shaking.png, 02-new-york-arrival.png.
- 확인한 브라우저 화면은 1440×1143. 16:9 전시장 화면 및 새 UI의 모바일 검증은 아직 하지 않았다.
- app.js, art-scene.js, fairy-video.js 문법 검사와 check-motion.mjs 모두 통과.
- 실제 사람 손 인식, 실제 청감, 75인치 가독성, 9시간 연속 운영은 미확인.
- 전체 화면 버튼의 자동 조작은 브라우저에서 거부되어 안내 문구가 표시됐다. 전체 화면 성공으로 보고하지 않는다.
- verification/browser-check.cjs 및 browser-result.json은 이전 Three.js 버전의 기록이다. 현재 그래픽 버전의 검증 결과로 사용하지 않는다.
- 실행기는 실제 터미널 앱에서 유지한다. 임시 도구 실행 세션에만 의존하지 않는다.
- 현재 사용자 그래픽 확인 단계. 요청 없이 다음 도시나 유료 생성을 추가하지 않는다.
