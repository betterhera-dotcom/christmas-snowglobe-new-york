## 변경
얼굴 감지 성공을 조작 허용의 조건으로 삼던 코드를 몸(양어깨/팔/손목) 기준으로 교체했다. 새 Lite 모델은 로컬 동봉. 얼굴 모델은 도시 고개 조작용으로만 뒤늦게 준비한다. 어깨와 손이 화면에 들어와야 하며, 모델 자체의 몸 검출률은 실제 카메라 확인이 필요하다.

카메라 권한 요청과 커튼 열기는 3D 모델/음악 준비를 기다리지 않는다. 대기 중 마우스 선택 가능, 권한 거절과 모델 실패 시 재시도 가능, 취소 후 뒤늦게 허용된 스트림은 중지한다. 이미 차단된 브라우저/OS 권한은 직접 허용해야 한다. 초기3D 준비는 첫 시점만, 나머지 도시 시점은 진입할 때 준비하므로 도시 첫 진입에서 추가 준비 지연이 생길 수 있다.

사진의 손 분석390~601ms가 일률적으로 버려지던 제한을700ms로 조정하고 연속 표본/화면 표시/속도 계산과 연결했다. 실제 처리시간을 단축했다고 주장하지 않는다. 몸 소실 즉시 해제, 오래된 프레임과 이전 세션 결과 거부, 입력 중단 후 추가 힘0 유지.
