뉴욕 스노우볼 — 1차 핵심 체험 시험판
작성: 2026-11-11

실행
1. 이 폴더의 ‘스노우볼 실행.command’를 두 번 클릭합니다.
2. Chrome에서 ‘카메라로 시작’을 누르고 카메라 사용을 허용합니다.
3. 한 손의 손바닥이 보이도록 들어 좌우로 흔듭니다.
4. 손을 높이면 스노우볼도 조금 올라갑니다. 주먹을 쥘 필요는 없습니다.
   빠르게 좌우로 약 2초간 계속 흔들면 눈보라를 지나 뉴욕 내부로 들어갑니다.
   도착 후 ‘스노우볼로 돌아가기’를 누르면 다시 시험할 수 있습니다.
5. 천천히 흔들기 → 빠르게 흔들기 → 손 멈추기를 비교합니다.
6. ‘처음으로’를 누르면 카메라와 음악을 멈추고 눈을 초기화합니다.

카메라 전에도 ‘마우스로 먼저 체험’을 눌러 스노우볼 위에서 좌우로 움직일 수 있습니다.
눈은 이동 속도에 반응하므로 클릭하거나 누르고 있을 필요가 없습니다.
‘손 인식 확인’을 펼치면 좌우가 거울처럼 보이는 카메라 미리보기가 나옵니다.
‘전체 화면’으로 전시장 화면에 맞춰 볼 수 있습니다.
실행 중에는 터미널 창을 열어두세요. 서버 종료는 그 창에서 Control+C입니다.
이미 서버가 열려 있다면 http://127.0.0.1:8876 에 접속합니다.
index.html을 파일로 직접 열면 모듈과 카메라 인식이 작동하지 않을 수 있습니다.

이번 버전에서 확인할 것
- 천천히 흔들 때와 빠르게 흔들 때 눈의 차이가 충분한가?
- 멈춘 뒤 눈이 내려앉는 시간이 자연스러운가?
- 같은 징글벨 멜로디의 빠르기 변화가 흔드는 느낌과 맞는가?
- 손을 잠깐 숨겼다가 다시 보여줄 때 갑자기 눈보라가 생기지 않는가?

구현 범위
- Three.js 기반 뉴욕의 크리스마스트리와 도시를 단순화한 입체 미니어처
- MediaPipe 한 손 추적, 손의 위치에 따른 작은 이동과 들어 올림
- 기존보다 3.2~4.8배 큰 두 크기의 눈 1,400개: 상승·회전·가라앉음
- 합성 종소리로 연주한 징글벨 후렴. 빠르기 72~158 BPM, 음높이 고정
- 빠른 좌우 왕복 반복 시 3.6초 눈보라·시점 전진 후 같은 미니어처 도시 내부 도착
- 도시 안에서는 별도 눈 600개가 가까운 곳과 먼 곳에서 내림
- 마우스 시험, 음소거, 초기화, 전체 화면, 카메라 오류 안내
- 라이브러리와 모델을 모두 로컬에 보관. 카메라 영상 저장·전송 없음

아직 구현하지 않은 것
- 실사풍 가상 손과 실제 잡기 동작
- 문·노크·제자리걸음·도시 선택·고개 돌리기
- 실사풍 도시 내부 (현재는 기존 입체 미니어처 안으로 들어가는 방식)
- 90초 전체 체험 제한과 무인 회차 운영
이 단계는 반복 시험이 목적이므로 90초에 자동으로 끝나지 않습니다.
뉴욕 내부에서는 현재 고정 시점으로 감상하며 고개 돌리기 기능은 아직 없습니다.
합성 음악은 반응 시험용이며 최종 녹음 음원이 아닙니다.
