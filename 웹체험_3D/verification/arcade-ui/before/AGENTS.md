# 뉴욕 스노우볼 핵심 체험 시험

사용자의 새 전시 프로젝트다. 상위 폴더의 꽃 프로젝트는 수정하지 않는다.
프로젝트의 karpathy-guidelines를 읽고, 사용자가 요청한 현재 단계만 진행한다.

## 사용자 확정 조건
- 전시 《손끝에서 열리는 크리스마스》, 콘텐츠 《스노우볼 세계여행》.
- 14일, 매일 09:00~18:00, 20~30대, 75인치 스크린 한 대·웹캠·스피커·노트북.
- 한 번에 1명, 최대 90초, 도시 한 곳만 방문해도 됨. 조기 종료 가능.
- 뉴욕·파리·서울. 음악은 같은 곡의 음높이를 유지하고 흔들림에 따라 빨라짐.
- 전체 전시 16,000명과 개별 체험 이론상 최대 4,320명을 구분한다.
- 최신 요청: 개발은 이틀 안에, 뉴욕부터, 가장 중요한 스노우볼 장면부터 시험.

## 현재 구현
- 별도 로컬 웹 앱. 시작 파일 index.html, Python 실행기 serve.py, 스노우볼 실행.command.
- Three.js 입체 미니어처, 1,400개 눈 입자, MediaPipe 한 손 추적.
- 합성 징글벨 후렴을 음높이 변화 없이 72~158 BPM으로 연주.
- 카메라/마우스 시험, 눈의 관성, 빠른 왕복 시 눈보라와 실제 도시 내부 진입, 초기화·음소거·전체화면.
- 라이브러리와 모델은 vendor에 고정 버전으로 보관. 입력 영상 저장·전송 없음.
- grabbing 판별이나 실사풍 손은 없고, 손바닥을 보여 움직이면 스노우볼이 따라간다.
- 본 시험은 반복 확인용. 90초 전체 회차·고개 추적·문 장면은 아직 구현하지 않았다.

## 2026-11-11 눈 크기와 도시 진입 수정
- 사용자가 눈이 너무 작고 빠르게 흔들어도 안으로 들어가지 않는다고 지적했다.
- 눈 크기를 .025에서 .08/.12로 확대하고 중심이 선명한 전용 입자 질감을 사용한다.
- 연속 4회 빠른 방향 전환 + 충분한 에너지에서 진입. 저속/떨림/재인식으로는 진입하지 않음.
- 3.6초 동안 원근 카메라가 실제 전진하고 시야가 넓어지며 눈보라·방사형 눈 궤적을 표시.
- 동일한 뉴욕 미니어처 내부의 트리와 건물 사이, 눈높이로 도착. 별도 600개 눈 입자로 원근 표현.
- 실사풍 도시나 머리 방향 감상은 아직 아님. ‘스노우볼로 돌아가기’로 초기화 가능.
- Chrome 실제 마우스 왕복으로 진입·도착·복귀를 확인했다. 화면: verification/05-inside-new-york.png.
- check-motion.mjs에 저속 무진입, 카메라 15fps 빠른 왕복 진입, 추적 재획득 누적 방지를 추가해 통과.
- browser-check.cjs는 변경된 진입 기대값으로 갱신했으나 이번 수정에서는 해당 전체 자동 검사를 재실행하지 않았다. 기존 browser-result.json은 수정 전 기록이다.
- 실제 사람의 손을 통한 새 임계값 확인은 사용자 체험이 필요하다.
- 로컬 서버는 터미널 앱에서 스노우볼 실행.command로 실행해 대화 종료 후에도 유지한다. 도구의 임시 실행 세션에만 의존하지 않는다.

## 검증
- verification/check-motion.mjs: 정지·떨림·왕복·추적 이탈·재인식·급격한 좌표 변화 검사 통과.
- verification/browser-check.cjs: 별도 Chrome에서 포인터 시험 및 가짜 카메라 입력 검증.
- 모델 로드/추론, 눈 상승·가라앉음, 템포 상승·복귀, 초기화, 카메라 트랙 정리, 390px 넘침 없음.
- JS 예외와 외부 요청 0. 수치는 verification/browser-result.json.
- 실제 사람 손 인식/실제 청감/전시장 장비/9시간 연속 운영은 아직 확인하지 않았다.
- 현재 사용자 확인을 기다리는 단계. 요청 없이 다음 장면을 추가하지 않는다.
