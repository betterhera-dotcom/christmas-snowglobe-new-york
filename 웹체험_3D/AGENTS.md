- 실제 Chrome 마우스 입력: 요정 접근과 영상 재생, 눈 반응과 BPM 변화, 아이콘 0/3→3/3, 뉴욕 도착, 좌우 보기, 매장 복귀 확인.

- 현재 사용자 그래픽 확인 단계. 요청 없이 다음 도시나 유료 생성을 추가하지 않는다.
